一、先搞懂布尔表达式

条件语句的核心是判断真假，所以得先明白什么是「真」什么是「假」。

1.1 什么是布尔表达式

布尔表达式就是结果为 True 或 False 的式子。

1.2 比较运算符

用来比较两个值，结果是布尔值。

运算符 含义 示例 结果
> 大于 5 > 3 True
>= 大于等于 5 >= 5 True
< 小于 5 < 3 False
<= 小于等于 5 <= 3 False
== 等于 5 == 5 True
!= 不等于 5 != 3 True

⚠️ 判断相等用 ==，不是 =。
单个 = 是赋值，== 才是比较。这是所有编程语言通用的坑。

链式比较（Python 特有）：

C 语言里必须拆成 x > 1 && x < 10，Python 可以直接连着写，更符合数学直觉。

1.3 逻辑运算符

用来组合多个条件。

运算符 含义 等价于 C
and 与，两边都真才真 &&
or 或，一边真就真 ||
not 非，取反 !

二、缩进：Python 最重要的语法规则

在讲 if 之前，必须先说缩进 —— 这是 Python 和 C 最大的区别之一。

2.1 C 语言用 {}，Python 用缩进

C 语言靠 {} 界定代码块，Python 只靠缩进。

2.2 规则

  • 同一层级的语句，缩进必须完全一致
  • 官方推荐 4 个空格（不要混用 Tab）
  • 缩进错误 = 语法错误，程序直接跑不起来

九、Python 与 C 条件语句对比

项目 C 语言 Python
条件括号 if (x > 0) 必须有括号 if x > 0: 不加括号
代码块 { } 缩进
冒号 无 if 后面必须有 :
else if else if elif
逻辑运算 && || ! and or not
链式比较 不支持 1 < x < 10 ✅
三元运算 条件 ? a : b a if 条件 else b
switch 有 Python 3.10 前没有（用 if-elif 代替）

最需要注意的三点：

  1. if 后面要有冒号 :
  2. 用 elif，不是 else if
  3. 缩进决定代码块归属，缩进错就是语法错

十、常见错误汇总

# 错误 报错 怎么避免
1 if 后漏冒号 SyntaxError 记住 if 条件:
2 缩进不一致 IndentationError 统一 4 空格，别混 Tab
3 = 写成 == 逻辑错误 比较用 ==
4 写 else if SyntaxError Python 是 elif
5 else 后加条件 SyntaxError else 不写条件
6 用了 && || SyntaxError 用 and or not
7 elif 顺序颠倒 逻辑错误 严格条件写前面
8 中文标点 SyntaxError 冒号引号用英文
9 判断 float 相等 精度问题 用 abs(a-b) < 1e-6
10 input 没转类型 TypeError int(input())

十一、快速上手模板

写条件语句的检查清单：

  • if / elif / else 后面都有冒号
  • 代码块的缩进一致（4 空格）
  • 比较用 ==，不是 =
  • 多条件用 and / or，不是 && / ||
  • 是 elif，不是 else if
  • elif 的顺序从严格到宽松
