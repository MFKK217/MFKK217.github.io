一、常量和表达式

1.1 什么是常量

常量就是直接写在代码里的、固定不变的值，也叫字面量（literal）。

这些 1、1.5、'hello' 就是常量，写死在代码里，运行时不会变。

二、变量和类型

2.1 变量是什么

变量就是一块用来存数据的内存空间，可以把它想成一个贴了标签的盒子。

和 C 语言最大的区别：Python 变量不需要声明类型，直接赋值就能用。

2.2 变量命名规则

必须遵守：

  • 只能由字母、数字、下划线组成
  • 不能以数字开头
  • 不能使用关键字（if、for、while、class 等）
  • 区分大小写

建议遵守（好习惯）：

  • 见名知意，别用 a b c 到处飞
  • 多个单词用下划线：student_name、total_score
  • 常量用全大写：PI = 3.14159
  • 不要用拼音和英文混搭

Python 官方推荐 小写 + 下划线 风格（snake_case）。

六、Python 与 C 语法对比

如果先学了 C，这张表能帮你快速切换：

项目 C 语言 Python
变量声明 必须写类型 int a; 不用声明 a = 10
变量类型 固定，不能变 动态，可以变
整数除法 7/2 得 3 7/2 得 3.5，整除用 //
自增 a++ **没有 ++**，用 a += 1
逻辑运算 && `
语句结尾 必须 ; 不用分号
代码块 { } 缩进（4 个空格）
类型转换 (int)x int(x)
输出 printf("%d", a) print(a)
输入 scanf("%d", &a) a = int(input())
字符串 字符数组 + \0 str 类型，不用管 \0
整数范围 有限，会溢出 无限大，不溢出

最需要重新习惯的三点：

  1. 缩进就是语法 —— Python 用缩进界定代码块，缩进错了直接报错
  2. 没有 ++ —— 写 a += 1
  3. / 永远得浮点数 —— 要整除用 //

七、常见错误汇总

# 错误 表现 怎么避免
1 缩进不一致 IndentationError 统一用 4 个空格，别混 Tab
2 input 没转类型 运算报 TypeError 用 int(input())
3 True 写成 true NameError 布尔值首字母大写
4 用了 a++ SyntaxError Python 没有自增，用 a += 1
5 = 当成 == 判断永远成立 判断用 ==
6 中英文符号混用 SyntaxError 括号引号用英文
7 字符串没加引号 NameError 文本要加 '' 或 ""
8 混用 / 和 // 结果不符合预期 要小数用 /，要整数用 //
9 变量名用了关键字 SyntaxError 避开 if for class 等
10 除数为 0 ZeroDivisionError 运算前判断

小结

Python 基础语法就这几块：

最需要记住的三件事：

  1. input 返回字符串，做数学运算必须先 int() 转换
