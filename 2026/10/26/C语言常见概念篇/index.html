发表于2026-10-26|更新于2026-11-02|学习笔记

这是 C 语言系列的第一篇，对应视频课程的第 1 章「C语言常见概念」。

在写代码之前，先把这些绕不开的基础概念搞清楚：程序是怎么跑起来的、字符在计算机里怎么存、字符串为什么会有乱码、注释该怎么写。

每节以知识点讲解为主，个别章节末尾配了 OJ 小题做补充练习（标注「补充」，跳过不影响知识体系）。

1.1 C 语言是什么

C 语言是一门编译型的计算机语言，写出来的代码叫源程序（.c 文件），它不能直接运行，要经过编译才能变成可执行程序。

编译型 vs 解释型：

类型 特点 代表语言
编译型 一次性全部翻译成机器码，运行快 C / C++
解释型 边读边翻译边执行 Python

为什么先学 C：

  • 底层，能理解内存和程序运行机制
  • 语法简洁，关键字只有 32 个
  • 学了 C 再学 C++ / Java 会轻松很多

1.3 main 函数

主函数，程序的入口。

要点：

  • 每个 C 程序有且只有一个 main 函数
  • 程序从 main 的第一行开始执行，到 main 结束
  • int 是返回值类型，return 0 表示正常结束
  • void main() 是错误写法，标准写法是 int main() 或 int main(void)

即使程序写了很多其他函数，也一定是从 main 开始跑的。

1.4 printf 与库函数

printf

printf 是格式化输出函数，把内容打印到屏幕。

占位符（后面第 2.11 节详细讲）：

%d 整数 int
%c 字符 char
%f 单精度浮点 float
%lf 双精度浮点 double
%s 字符串
%p 地址

库函数

printf 不是 C 语言自带的语法，而是标准库提供的函数。

1.5 关键字

C 语言保留了一批单词，有专门含义，不能拿来当变量名。

初学先记住这几个：

关键字 含义
int char float double 数据类型
if else switch 分支
for while do 循环
return 返回
sizeof 计算大小
const 常量

关键字全部小写，且不能自己创造。

计算机只认二进制，字符要存进内存，需要一个编号 —— 这就是 ASCII 编码。

'a' ~ 'z' 97 ~ 122
'0' ~ '9' 48 ~ 57
' '（空格） 32
'\n'（换行） 10

1.7 字符串与 \0

C 语言用双引号表示字符串：

关键：字符串末尾自动隐藏一个 \0（转义字符，ASCII 值 0），它是字符串的结束标志。

验证一下：

%s 打印字符串时，会一直打印到遇到 \0 为止。
没有 \0 就会继续往后读内存，直到碰巧遇到一个 0 —— 于是出现乱码。

所以字符串长度要多算一个 \0 的位置。

1.8 转义字符

以 \ 开头的特殊字符，用来表示无法直接打出来的字符。

转义字符 含义
\n 换行
\t 制表符（Tab）
\\ 一个反斜杠 \
\' 单引号 '
\" 双引号 "
\0 字符串结束标志
\ddd 八进制表示的字符，如 \130 是 'X'
\xdd 十六进制表示的字符，如 \x41 是 'A'

1.9 语句的分类

C 语言的语句分五大类：

类型 说明 示例
空语句 只有一个分号 ;
表达式语句 表达式加分号 a = 10;
函数调用语句 调用函数加分号 printf("hi");
复合语句 用 {} 包起来的一段 { int a; ... }
控制语句 控制程序流程 if for while return

复合语句（代码块）：{ } 里面可以定义变量，形成一个独立的作用域。

1.10 注释

注释是给人看的，编译器会直接忽略。

注意：

  • 注释不能嵌套（/* /* */ */ 是错的）
  • 注释里的代码不会执行
  • 双引号里的 // 不是注释，是字符串内容

补充练习：输出 Hello, World!

注意：OJ 要求输出什么就输出什么，别自己加提示语。

小结

这一篇的知识链条：

这篇最需要记住的三件事：

  1. 每条语句以分号 ; 结尾 —— 漏写就编译失败
  2. 字符串末尾自动带 \0 —— 字符数组没加就会输出乱码
  3. main 是程序入口 —— 有且只有一个，标准写法 int main()
