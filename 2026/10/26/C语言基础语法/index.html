一、第一个程序

部分 干什么
#include <stdio.h> 引入标准输入输出库，要用 printf / scanf 就必须有
int main() 主函数，程序从这里开始，每个程序必须有且仅有一个

return 0 程序结束，0 表示正常
; 语句结尾必须有分号，新手第一大坑

::: warning
OJ 题目经常要求「不要输出多余内容」。
如果题目说输出 Hello, World!，那就一个字不多一个字不少，别自己加 printf("请输入...") 之类的提示语。
:::

::: tip

取值范围

类型 大概范围
int ±21 亿
long long ±9.2×10¹⁸
float 6~7 位有效数字
double 15~16 位有效数字

数超过 21 亿要用 long long，对应格式符 %lld。

八、新手最常踩的 8 个坑

# 坑 后果 怎么避
1 忘写分号 ; 编译失败 每条语句结尾检查
2 scanf 忘加 & 崩溃 / 乱码 除了数组都要加
3 整数除法 7/2 得 3 不是 3.5 写 a * 1.0 / b
4 double 用错格式符 输出 0 或乱码 scanf 用 %lf，printf 用 %f
5 变量没初始化 垃圾值 定义时就赋初值
6 多输出了提示语 OJ 判错 题目要什么输出什么
7 数太大溢出 结果变负 超过 21 亿用 long long
8 中英文符号混用 编译失败 分号引号都用英文的

十、解题套路小结

拿到题目按这个顺序走：

  1. 看清输入格式 —— 几个数？什么类型？空格还是逗号分隔？
  2. 选对变量类型 —— 整数用 int，超大用 long long，小数一律 double
  3. 看清输出格式 —— 保留几位小数？要不要换行？有没有多余空格？
  4. 注意整数除法 —— 要求小数结果时一定 * 1.0
  5. 不要输出提示语 —— OJ 只认结果
