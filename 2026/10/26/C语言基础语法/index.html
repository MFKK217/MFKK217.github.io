第一部分　C语言常见概念

1.1 C 语言是什么

C 语言是一门编译型的计算机语言，写出来的代码叫源程序（.c 文件），它不能直接运行，要经过编译才能变成可执行程序。

编译型 vs 解释型：

类型 特点 代表语言
编译型 一次性全部翻译成机器码，运行快 C / C++
解释型 边读边翻译边执行 Python

为什么先学 C：

  • 底层，能理解内存和程序运行机制
  • 语法简洁，关键字只有 32 个
  • 学了 C 再学 C++ / Java 会轻松很多

1.3 main 函数

主函数，程序的入口。

要点：

  • 每个 C 程序有且只有一个 main 函数
  • 程序从 main 的第一行开始执行，到 main 结束
  • int 是返回值类型，return 0 表示正常结束
  • void main() 是错误写法，标准写法是 int main() 或 int main(void)

即使程序写了很多其他函数，也一定是从 main 开始跑的。

printf

%s 字符串
%p 地址

printf 不是 C 语言自带的语法，而是标准库提供的函数。

1.7 字符串与 \0

C 语言用双引号表示字符串：

关键：字符串末尾自动隐藏一个 \0（转义字符，ASCII 值 0），它是字符串的结束标志。

验证一下：

%s 打印字符串时，会一直打印到遇到 \0 为止。
没有 \0 就会继续往后读内存，直到碰巧遇到一个 0 —— 于是出现乱码。

所以字符串长度要多算一个 \0 的位置。

1.8 转义字符

以 \ 开头的特殊字符，用来表示无法直接打出来的字符。

转义字符 含义
\n 换行
\t 制表符（Tab）
\\ 一个反斜杠 \
\' 单引号 '
\" 双引号 "
\0 字符串结束标志
\ddd 八进制表示的字符，如 \130 是 'X'
\xdd 十六进制表示的字符，如 \x41 是 'A'

第二部分　数据类型和变量

2.1 数据类型总览

C 语言提供的数据类型分两大类：内置类型和自定义类型。

本篇只讲内置类型。

2.2 字符型 char

  • 大小：1 字节
  • 范围：有符号 -128 ~ 127，无符号 0 ~ 255
  • 本质存的是 ASCII 值，所以 char 也能当小整数用

2.3 整型

用来表示整数，分四种，区别是占用空间不同：

short int、long int 是完整写法，可以省略 int。

选型建议：

场景 用什么
普通整数 int（最常用）
省内存的小范围数 short
超过 21 亿的大数 long long

2.4 浮点型

用来表示小数：

区别：

类型 大小 有效数字
float 4 字节 6~7 位
double 8 字节 15~16 位

默认小数是 double 类型。
写 float f = 3.14; 会有精度警告，应该加 f 后缀：3.14f

**初学一律用 double**，精度高，不容易出问题。

2.5 布尔型

C99 标准引入，用来表示真假。

  • 取值只有 true（1）和 false（0）
  • 需要包含 <stdbool.h>
  • 早期 C 语言用 0 表示假、非 0 表示真

初学阶段不常用，知道有这个东西就行。

2.6 signed 与 unsigned

这两个关键字修饰整型和字符型，决定能不能表示负数。

对比：

类型 范围（4 字节）
int（signed） -21 亿 ~ 21 亿
unsigned int 0 ~ 42 亿

同样的字节数，unsigned 的最大值翻倍，因为它把原本表示负数的那一半也用来表示正数。

注意：

  • char 默认是否有符号，C 标准没规定，由编译器决定
  • 所以写 char 要明确：signed char 或 unsigned char
  • 初学不要混用 signed 和 unsigned，容易踩坑

2.7 数据类型的取值范围

每种类型能表示的数是有上限的，超出就溢出。

short 2 字节 -32768 ~ 32767

int 4 字节 -2147483648 ~ 2147483647
unsigned int 4 字节 0 ~ 4294967295
long long 8 字节 约 ±9.2×10¹⁸
float 4 字节 约 ±3.4×10³⁸

2.9 变量

变量的创建

语法：类型 + 变量名

创建的同时给值，叫初始化：

局部变量不初始化，值是随机的垃圾值，直接用会出错。
做累加时必须写 int sum = 0;

变量的命名规则

必须遵守：

  • 只能由字母、数字、下划线组成
  • 不能以数字开头
  • 不能使用关键字
  • 区分大小写

建议遵守（好习惯）：

  • 名字有意义，别用 a b c 到处飞
  • 多单词用下划线或驼峰：student_age 或 studentAge
  • 局部变量用小写，常量用大写

变量的分类

类型 位置 作用域 生命周期
局部变量 {} 内部 只在该代码块内有效 进入创建，出了销毁
全局变量 {} 外部 整个程序 程序运行期间一直存在

全局变量不初始化会自动赋 0，局部变量不会 —— 这是重要区别。

常见错误汇总

# 错误 表现 怎么避免
1 漏写分号 编译失败 每条语句结尾检查
2 scanf 忘加 & 崩溃 / 乱码 除数组外都要加
3 整数除法 7/2 得 3 不是 3.5 写 a * 1.0 / b
4 double 格式符错 输出 0 或乱码 scanf 用 %lf，printf 用 %f
5 变量未初始化 结果随机 定义时就赋初值
6 中英文符号混用 编译失败 分号引号用英文
7 = 当成 == 判断永远为真 写 if (1 == a)
8 数太大溢出 结果变负数 超过 21 亿用 long long
9 % 用于小数 编译失败 用 fmod()
10 float 精度不够 结果有误差 一律用 double
11 字符数组没 \0 输出乱码 用双引号字符串，或手动加 \0
12 scanf 读字符 读到换行符 %c 前加空格

小结

最需要警惕的三件事：

  1. scanf 的 & —— 漏了就崩
  2. 整数除法 —— 7/2 是 3 不是 3.5
  3. double 的格式符 —— 输入 %lf，输出 %f
